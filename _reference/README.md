# Upload pack

1. Copy this whole `_reference` folder into the root of your site's repository on GitHub and commit it.
2. In Netlify, open the project, go to Agent Runs and start a new run in the mode that makes changes (not Ask mode).
3. Paste the short prompt from the guide. The agent reads `BRIEF.md` for the full instructions.
4. Review the Files changed tab and the Deploy Preview before you ship anything.
