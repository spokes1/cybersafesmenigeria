# Nigeria applicability review (editorial evidence)

**Review date:** 8 November 2026. Availability is not synonymous with familiarity, local support, or every device's compatibility.

| Service | Position | Evidence and caveat |
|---|---|---|
| Google Account Security Checkup and Google Password Manager | Core | Official Google instructions for Chrome/Android accounts; suitable where those accounts are actually used, not proof of Nigerian adoption |
| Google Play Protect | Core, supported Android only | Google official Play Protect documentation; check the user's phone has Google services and is supported |
| Windows Security/Microsoft Defender Antivirus | Core, supported Windows | Built into supported Windows devices, according to Microsoft. Do not confuse with separately marketed Microsoft Defender subscription product |
| Google Authenticator | Core MFA option | Official Google instructions and Nigerian Apple App Store listing; codes can be generated offline after setup; recovery planning still required |
| Microsoft Authenticator | Core/optional for Microsoft users | Nigerian Apple App Store listing and Microsoft guidance; not necessarily needed by all businesses |
| Google Drive and Microsoft OneDrive | Familiar document-storage options | Official help docs; OneDrive Nigerian App Store listing. Distinguish file sync from independently recoverable backup; assess business-account ownership and internet costs |
| Apple Find My and Google Find Hub | Core if compatible phone | Official platform guidance; device and account settings vary |
| Bitwarden | Additional option | Official downloads and Nigerian Apple App Store listing. Free individual plan is not equivalent to business team-management features |
| Have I Been Pwned | Optional check | Accessible public browser service with published scope; do not claim Nigeria-specific usage or full breach coverage |
| No More Ransom | Specialist | Official international recovery resource; decryption availability depends on ransomware family |
| VirusTotal | Caution, not a general recommendation | Public-submission privacy risks; never suggest uploading customer or company-confidential documents |
| ngCERT | Nigerian official support | https://cert.gov.ng/rfc2350 and https://cert.gov.ng/incident-report/corporate |
| Nigeria Police Force National Cybercrime Centre | Nigerian official reporting | https://nccc.npf.gov.ng/ereport/ |
